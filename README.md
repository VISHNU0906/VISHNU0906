### 🔬 AI &amp; LLM security
- **[autoforge](https://github.com/VISHNU0906/autoforge):** finds new ways to jailbreak language models on its own, sorts them into classes, and tests which survive common defenses.
- **[refusal-climb](https://github.com/VISHNU0906/refusal-climb):** uses how strongly a model is refusing as a search signal to surface new jailbreak classes and check whether they transfer to other models.
- **[taint](https://github.com/VISHNU0906/taint):** catches when an AI agent gets hijacked by hidden instructions planted in a page, a file, or a tool's output.
- **[mirage](https://github.com/VISHNU0906/mirage):** a deliberately broken LLM app plus an attack toolkit, with a hardened build that closes every hole.
- **[mcp-injection-scanner](https://github.com/VISHNU0906/mcp-injection-scanner):** scans Model Context Protocol servers for prompt injection and tool hijacking.
- Also: **[promptstrike](https://github.com/VISHNU0906/promptstrike)** &nbsp;·&nbsp; **[agentssrf](https://github.com/VISHNU0906/agentssrf)** &nbsp;·&nbsp; **[llm-policy-guard](https://github.com/VISHNU0906/llm-policy-guard)**

### ☁️ Cloud &amp; application security
- **[gatekeeper](https://github.com/VISHNU0906/gatekeeper):** a CI/CD security gate that merges many scanners into one clean report, with baseline-diffing and false-positive triage.
- **[cloudrange](https://github.com/VISHNU0906/cloudrange):** a vulnerable AWS range, an attack chain for IAM privilege escalation, and an auditor that maps the paths back to fixes.
- Also: **[iamscout](https://github.com/VISHNU0906/iamscout)** (IAM / S3 misconfig auditor) &nbsp;·&nbsp; **[apiraider](https://github.com/VISHNU0906/apiraider)** (OWASP API Top 10 tester)

### 📊 Security observability &amp; SRE
